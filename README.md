# Binder

Classeur Magic en ligne : on colle une liste au format Moxfield, elle s'affiche comme un vrai classeur (pages de 4 ou 9, tournage de pages), avec les images Scryfall et le prix Cardmarket sous chaque carte.

- Site : https://binderinho.netlify.app
- Tout le site tient dans `index.html`. Chaque modification poussée sur `main` est republiée automatiquement par Netlify.
